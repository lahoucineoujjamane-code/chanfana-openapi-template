# 🌿 طبيب الأعشاب — موسوعة الطب والأعشاب والزيوت (تطبيق أندرويد)

تطبيق عربي يعمل **دون إنترنت** يجمع معلومات الأمراض وأعراضها وعلاجها الطبي والتقليدي، مع التركيز على **الأعشاب والزيوت** من مختلف ثقافات العالم، و**محلل أعراض** يرجّح المرض المحتمل حسب الأعراض والعمر والجنس.

## المحتوى

| القسم | العدد |
|---|---|
| الأمراض (بأعراضها، أسبابها، علاجها الطبي، الأعشاب، الزيوت، الوصفات التقليدية، متى تراجع الطبيب) | 73 |
| الأعراض مجمّعة حسب أجهزة الجسم | 141 |
| الأعشاب (الاستعمال، التحضير، جرعة البالغ والطفل، الأمان في الحمل، موانع الاستعمال والتداخلات) + 4 أعشاب سامة للتحذير | 67 |
| الزيوت العطرية والناقلة (الاستعمال، التخفيف، التحذيرات) | 22 |
| الأدوية الحديثة الشائعة وجرعاتها | 31 |
| أنظمة الطب التقليدي: العربي والنبوي، المغربي والأمازيغي، اليوناني الإسلامي، الفارسي، الصيني، الأيورفيدا، الكامبو الياباني، الأوروبي، الأفريقي، الأمريكي الأصلي، أمريكا اللاتينية | 11 |

## المزايا
- **🩺 محلل الأعراض:** خانات العمر (سنوات/أشهر)، الجنس، الحمل، مدة الأعراض، واختيار الأعراض بالبحث أو حسب جهاز الجسم. يعرض عدة احتمالات مرتبة بنسبة ترجيح، مع الأعراض المتطابقة والأعراض المميزة الناقصة، والحلول المقترحة لكل احتمال.
- **🚨 علامات الخطر:** ينبّه فوراً عند أعراض تستدعي الطوارئ (الجلطة القلبية والدماغية، التهاب السحايا، الزائدة، النزيف، حمى الرضيع، الصدمة التحسسية…).
- **🤰 تنبيهات الحمل والأطفال:** تُعلَّم الأعشاب الممنوعة في الحمل، وتظهر جرعات الأطفال عند إدخال عمر طفل.
- **🧮 حاسبة جرعات الأطفال** (باراسيتامول وإيبوبروفين) حسب الوزن وتركيز الشراب.
- **☠️ قسم الأعشاب الخطيرة** (الحرمل، الفليو، الدفلى، الداتورة).
- بحث عربي ذكي (يتجاهل التشكيل والهمزات)، المفضلة، الوضع الليلي، زر الرجوع في أندرويد.

## كيف يعمل الترجيح؟
لكل مرض أعراض بأوزان (3 مميز، 2 شائع، 1 ممكن). الدرجة = 0.55 × (نسبة أوزان أعراض المرض التي ذكرتها) + 0.45 × (نسبة أعراضك التي يفسرها المرض)، ثم تُضرب في معامل الفئة العمرية والجنس ومدة الأعراض، وتُحوَّل إلى نسب ترجيح نسبية بين الاحتمالات المعروضة. الكود في `www/js/engine.js`.

## الحصول على ملف APK
كل دفع (push) يغيّر مجلد `medicine-app` يشغّل GitHub Actions (`.github/workflows/medicine-apk.yml`) فيبني الملف تلقائياً:
1. افتح تبويب **Actions** في المستودع ← آخر تشغيل لـ «طبيب الأعشاب».
2. نزّل **tabib-al-aashab-apk** من قسم Artifacts، وفكّ الضغط.
3. انقل `tabib-al-aashab.apk` للهاتف وثبّته (اسمح بالتثبيت من مصادر غير معروفة).

> الملف موقّع بمفتاح تصحيح ليُثبَّت مباشرة. للنشر على Google Play أنشئ مفتاح توقيع خاصاً بك في `android/app/build.gradle.kts`.

### البناء محلياً
```bash
cd medicine-app/android
./gradlew assembleRelease      # يحتاج Android SDK و JDK 17
# الناتج: app/build/outputs/apk/release/app-release.apk
```
أو افتح مجلد `medicine-app/android` في Android Studio واضغط Run.

### تجربة نسخة الويب
```bash
cd medicine-app/www && python3 -m http.server 8000   # ثم افتح http://localhost:8000
```
نسخة الويب نفسها تطبيق PWA قابل للتثبيت ويعمل دون إنترنت.

## الاختبارات
```bash
node medicine-app/tests/validate.mjs
```
يتحقق من سلامة كل الروابط بين البيانات (الأعراض، الأعشاب، الزيوت، الأدوية، الثقافات) ومن نتائج سيناريوهات تشخيصية معروفة وعلامات الخطر.

## البنية
```
medicine-app/
├── www/                     واجهة التطبيق (HTML/CSS/JS دون مكتبات خارجية)
│   ├── js/data/             قواعد البيانات: diseases, symptoms, herbs, oils, drugs, cultures
│   ├── js/engine.js         البحث وخوارزمية الترجيح وعلامات الخطر
│   └── js/app.js            الصفحات والتنقل
├── android/                 مشروع أندرويد (WebView يعرض www من داخل APK)
└── tests/validate.mjs       اختبارات البيانات والمحرك
```

## إضافة مرض أو عشبة
أضف عنصراً في الملف المناسب داخل `www/js/data/` باتباع نفس البنية، ثم شغّل `node medicine-app/tests/validate.mjs` للتأكد من صحة المعرّفات.
